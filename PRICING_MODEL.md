# Pricing Model

Public-safe pricing posture for the Razorglint painpoint-solver stack.

---

## Pricing principle

Price follows:

**pain severity + buyer risk + system depth + proof access + integration effort + license rights**

Higher severity pain, deeper system integration, and broader license rights command higher pricing. Naming the pain is free. Solving it at depth is paid.

---

## Tier pricing posture

| Tier | Pricing posture | Why |
|------|-----------------|-----|
| Free / Public Proof Reference | Free | Public education and trust-building. Naming pain, explaining systems, showing maps. |
| Starter | Low-friction entry | Basic memory/proof understanding. Low integration depth. Adoption support. |
| Professional | Paid proof/pilot tier | SAR, Truthpacks, Prestige-Forge, buyer-verifiable proof. Core governance evidence. |
| Operator | Higher-value controlled deployment / simulation pilot | FleetSim trust-plane, CTLM full, policy drift, authority modeling. |
| Enterprise | Full-stack governance review | High-assurance evidence, OpenClaw, regulatory-readiness mapping, air-gapped packages. |
| OEM / White-label | Negotiated | Embedding rights into buyer's platform. Per-module or per-system. |
| Strategic License | Negotiated | Exclusivity for vertical, geography, or use case. Competitive differentiation. |
| Private IP Sale / Acquisition | Negotiated | Full source + IP ownership transfer. |

---

## Pricing factors

| Factor | Lower price | Higher price |
|--------|-------------|--------------|
| Pain severity | S3/S4 | S1 Critical |
| System depth | Surface explanation | Full integration + custom proof |
| Proof access | Public maps | Custom Truthpacks + Merkle proofs |
| Integration effort | Self-service | Guided integration + support |
| License scope | Single-use | Multi-site / platform embedding |
| Exclusivity | Non-exclusive | Vertical/geography exclusive |

## Value anchors (not price floors)

| Tier | Value anchored to |
|------|-------------------|
| Free | Trust-building, pipeline entry |
| Starter | Reduced rework, basic operational continuity |
| Professional | Reduced investigation time, buyer-verifiable proof, audit-readiness support |
| Operator | Fleet trust visibility, authority modeling, continuous policy evaluation |
| Enterprise | Regulatory-readiness evidence, high-assurance custody chains, full governance review |
| OEM | Avoided build cost, accelerated time-to-market |
| Strategic | Market exclusivity, competitive moat |
| Acquisition | Avoided build-from-scratch cost, IP ownership |

---

## Pricing guardrails

1. **S1 Critical painpoints are never free at solution depth.** Naming them is free. Solving them is Professional or above.
2. **Enterprise-only painpoints (PP-015, PP-023, PP-024) are never discounted into lower tiers** without explicit tier upgrade.
3. **Pilot pricing reflects demonstration value, not full integration value.** A pilot shows capability — it does not transfer rights.
4. **Volume/multi-system discounts are negotiated, not automatic.**
5. **OEM and Strategic pricing reflects embedding or exclusivity value**, not per-seat licensing.
